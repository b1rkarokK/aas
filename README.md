# AI Router

Локальный AI coding workspace поверх OpenRouter. Программа умеет держать несколько твоих API-ключей, автоматически переключаться между ними и моделями, сохранять историю и работать с проектом как coding-agent.

## Что теперь умеет GUI

- **Чат** — обычный запрос к ИИ с историей и workspace-контекстом.
- **Изменить код** — ИИ читает проект, создаёт план изменений, применяет только нужные файлы и сохраняет backup в `.ai-router-backup/`.
- **Автопроверка** — после изменения запускаются syntax/typecheck, static/dead-code, lint и тесты. Если есть реальные ошибки, ИИ получает результат проверки и делает следующий цикл исправления. По умолчанию до 3 циклов.
- **Проверки** — ручной запуск тех же проверок без изменения файлов.
- **Статус** — дневной и минутный расход по моделям, количество API-ключей и реальный список моделей, который отдаёт OpenRouter для ключа.
- **Настройки** — пул API-ключей, описание каждого профиля и редактируемый системный prompt профиля.

### Профили

- `smart` — сложный код, архитектура, ревью и поиск причин ошибок.
- `agentic` — многошаговая работа с проектом: изменить → проверить → исправить.
- `bigcontext` — большой проект/много файлов.
- `fast` — небольшие правки и быстрые вопросы.

Профиль не является отдельной моделью: он задаёт инструкции и цепочку моделей. Сейчас по умолчанию используется `openrouter/free`, поэтому OpenRouter сам выбирает актуальную бесплатную модель. В статусе можно увидеть, какие модели реально доступны твоему API-ключу.

## API fallback

Можно добавить несколько своих ключей. При `429`, `401`, `402`, `403` или временной сетевой ошибке роутер пробует следующий ключ/endpoint. История чата и workspace не сбрасываются.

Ключи хранятся отдельно от проекта в `~/.ai_router_keys.json`.

## Установка

```bash
pip install -r requirements.txt
python gui.py
```

На Linux при отсутствии Tkinter:

```bash
sudo apt install python3-tk
```

Ключ можно добавить мышкой через **Настройки → API-ключи**. Переменная окружения `OPENROUTER_API_KEY` также поддерживается.

## Инструменты проверки

Для Python рекомендуется:

```bash
pip install ruff pytest
```

Для Node/TypeScript проект должен иметь соответствующие npm-зависимости (`eslint`, тестовый runner; для TypeScript — `typescript`). Команды задаются в `config.yaml`.

Проверка не заменяет реальные тесты проекта: AI Router запускает именно те инструменты, которые доступны в проекте и прописаны в конфиге.

## Backup и безопасность coding-agent

Перед перезаписью существующего файла создаётся копия в:

```text
<project>/.ai-router-backup/<timestamp>/
```

Coding-agent принимает от модели только относительные пути внутри выбранного workspace и не должен изменять `.git` или каталоги зависимостей. Всё равно держи Git/резервную копию проекта: автоматический агент не заменяет code review.

## MCP-инструменты (Penpot и другие)

AI Router умеет вызывать инструменты MCP-серверов (например, penpot-mcp-server)
прямо во время диалога — модель сама решает, когда прочитать/изменить макет.
Работает через `pip install mcp` и профиль `design` в `config.yaml`.

Настройка сервера — в `config.yaml -> mcp_servers`:

```yaml
mcp_servers:
  penpot:
    transport: "http"
    url: "http://localhost:8787/mcp"
    headers: {}   # при необходимости: Authorization: "Bearer ВАШ_ТОКЕН"
```

Команды:

```bash
python cli.py mcp-tools                              # список доступных инструментов
python cli.py mcp-ask "покажи мои проекты в Penpot"  # запрос с доступом к инструментам
```

`ask_with_tools()` в `router.py` использует тот же fallback по ключам/моделям,
что и обычный `ask()` — переключение между ключами и профилями не меняется.

## CLI

```bash
python cli.py ask "объясни ошибку" --profile smart
python cli.py check --fix
python cli.py status
```

## Современный GUI и инструменты

Новая версия использует **PySide6**, а не Tkinter: это полноценный desktop UI с карточками, боковой навигацией, профилями, streaming-чатыми и правой панелью проекта/статуса.

### Что установить на Windows

Минимум:
- Python 3.11+
- собственный OpenRouter API key

Для проверки проектов дополнительно полезны:
- Git — управление версиями и откатами;
- Ruff + pytest — Python lint/dead-code/tests;
- Node.js + npm/npx — JavaScript/TypeScript и ESLint;
- TypeScript — typecheck через `tsc`.

В проекте есть `setup_windows.ps1`: он создаёт `.venv`, устанавливает `requirements.txt` и, если найден npm, выполняет `npm install`.

Запуск: `start.bat`.

### Профили

**Обычная переписка** — только разговор с моделью. Workspace не изменяется и проверки не запускаются.

**Кодинг** — работа с workspace. Если включён `Автокод`, агент делает: анализ → генерация → применение → syntax/typecheck → dead-code → lint → tests → автоисправление ошибок до лимита циклов.
